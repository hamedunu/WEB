پروژه اندروید Web Fullscreen

امکانات:
- در شروع، یک فرم ساده برای وارد کردن آدرس سایت دارد.
- بعد از ورود، سایت درون خود برنامه باز می‌شود و نوار آدرس یا جستجو ندارد.
- حالت Immersive Sticky: نوار وضعیت و نوار پایین مخفی می‌شوند؛ با کشیدن از لبه‌ها ممکن است موقتاً ظاهر شوند.
- دکمه برگشت اندروید ابتدا به صفحه قبلی سایت می‌رود و سپس به فرم وارد کردن آدرس برمی‌گردد.
- JavaScript و DOM storage فعال هستند.

ساخت APK با Android Studio:
1. ZIP را استخراج کنید.
2. Android Studio را باز کنید و File > Open را بزنید و پوشه FullscreenWebApp را انتخاب کنید.
3. منتظر بمانید Gradle Sync کامل شود.
4. از منوی Build > Build Bundle(s) / APK(s) > Build APK(s) استفاده کنید.
5. APK در app/build/outputs/apk/debug/app-debug.apk قرار می‌گیرد.

این ZIP شامل سورس پروژه است، نه APK کامپایل‌شده؛ در این محیط Android SDK/Gradle نصب نیست تا APK قابل نصب تولید شود.
